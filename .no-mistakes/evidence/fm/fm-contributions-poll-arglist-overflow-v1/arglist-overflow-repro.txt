Contributions observer: large-backlog argv overflow fix — end-to-end evidence
=============================================================================

BUG: bin/fm-fleet-snapshot.sh --contribution-input passed the whole backlog JSON
through an argv argument (jq --argjson backlog "$BACKLOG_JSON"). Once data/backlog.md
grew so its parsed JSON exceeded the kernel single-argument limit (MAX_ARG_STRLEN,
~128 KiB), jq's exec failed with "Argument list too long", producing empty output.
fm-contributions.sh poll then reported "contributions: observation unavailable" for
every registered upstream PR.

  merged.json bytes: 630861
  structure OK: {backlog, tasks} preserved, 3000 records
